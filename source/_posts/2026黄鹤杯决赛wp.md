# 前言

第一次线下打AWDP这种模式的比赛，解出了web1的防御和web2的攻击。攻击部分和CTF解题差不多，防御部分是要求上传一个防御包，随后执行其中的update.sh脚本。由于比赛四个小时分成了8轮，防御每轮都会进行加分，所以早做防御后期滚雪球分数会变得很高，可惜由于经验不足一开始光顾着攻击了，并且web2的flag一交就没法开环境了，不然防御部分应该也能做出来的。

探测发现在`/api/books/obu/preview?file=`有目录穿越和文件读取漏洞，在读取文件之前加一个目录解析然后判断是否为安全目录即可

update.sh

```bash
#!/bin/bash

# 1. 定义目标路径（根据题目，应用目录是 /app/app）
# 请务必确认你的 Python 程序在容器里的准确位置
TARGET_DIR="/app/app"
PATCH_SOURCE="/patch.py"

echo "Starting defense update..."

# 2. 检查防御文件是否存在 (防止因解压异常导致脚本报错)
if [ -f "$PATCH_SOURCE" ]; then
    # 3. 使用【绝对路径】执行复制操作
    # 注意：这里必须是从 / 开始的完整路径
    cp "$PATCH_SOURCE" "$TARGET_DIR/patch.py"
    
    # 如果需要覆盖原有的逻辑文件，也请使用绝对路径
    # cp "$PATCH_SOURCE" "/app/app/main.py" 
    
    echo "Success: Patch deployed to $TARGET_DIR"
else
    echo "Error: Source patch file not found in root!"
    exit 1
fi

echo "Update complete."

```

patch.py

```python
import os

# 模拟原有的读取函数，加入安全补丁
def secure_load_preview(user_input_file, base_dir="/app/data/books/obu"):
    # 1. 获取绝对路径并标准化 (消除 ../)
    requested_path = os.path.abspath(os.path.join(base_dir, "preview", user_input_file))
    safe_base_dir = os.path.abspath(base_dir)

    # 2. 核心防御：检查解析后的路径是否仍在安全目录下
    if not requested_path.startswith(safe_base_dir):
        raise PermissionError("Security Alert: Attempted Path Traversal detected!")

    # 3. 如果校验通过，执行读取逻辑
    try:
        with open(requested_path, 'r') as f:
            return f.read()
    except Exception as e:
        return str(e)

print("Patch applied successfully.")
```
